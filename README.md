# 📝 ToDo – React Native Task Manager App

A fully functional task management mobile application built with React Native and Expo to efficiently manage daily tasks with add, view, complete, and delete functionalities, seamless navigation, and clean UI.

---

[Expo Snack Demo](https://github.com/abdelfatahmoustafa/ToDo-ReactNative) <!-- ضع رابط Expo Snack أو APK هنا إذا توفر -->

---

## ✨ Features

- **Add Tasks:** Add new tasks with title and description.
- **View Tasks:** See all tasks on the home screen with clear UI indicating completed and pending tasks.
- **Task Details:** Tap any task to view full details, mark as completed, or delete it.
- **Search & Sorting:** Includes a search bar and sorting UI (currently design only) to filter tasks by title or other parameters.
- **Easy Navigation:** Bottom Tab and Stack Navigation for smooth transitions between Home, Add Task, Details, and Settings screens.
- **Toast Notifications:** Success and error toast messages for task operations.

---

## 🖥️ Main Screens

- **HomePage:** Displays all tasks with add task button.
- **AddItems:** Add new task screen.
- **Details:** View full task details with complete and delete options.
- **Setting:** Settings screen (design only).
- **SearchHeader:** Search and sorting bar on HomePage.

---

## 🛠️ Tools & Libraries Used

- **React Native:** Building mobile UI components.
- **Expo:** For faster development, testing, and deployment.
- **Redux Toolkit & React-Redux:** State management for tasks.
- **@react-navigation:** Bottom Tabs and Stack Navigator setup.
- **react-native-toast-message:** For toast notifications.
- **react-native-uuid:** Generate unique task IDs.
- **@expo/vector-icons:** Ready-to-use icon packs.
